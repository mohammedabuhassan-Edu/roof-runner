# Rooftop Courier Run

3D endless runner: switch lanes on anime city rooftops, jump gaps, slide under low bars, collect packages.

## Run locally

```bash
npm install
npm run dev
```

## Controls

- **Desktop:** A/D or arrows to change lanes, Space to jump, S or Down to slide, P to pause
- **Touch:** swipe left/right for lanes, tap to jump, swipe down to slide
